## Missing metadata

These commonly used `setup()` arguments are not set:

| Argument | Effect when missing |
|---|---|
| `packages` / `py_modules` | No Python code is included unless discovered another way. Builds may be empty or incomplete. |
| `install_requires` | Runtime dependencies are not installed automatically. |
| `entry_points` | No console commands are installed. |
| `python_requires` | Installs are not restricted by Python version. |
| `long_description`, `long_description_content_type` | No long description on package pages. |
| `author`, `author_email`, `url`, `license` | No contact or licence metadata. |
| `classifiers` | No trove classifiers. |
| `include_package_data`, `package_data` | Non-code files are not included. |
| `extras_require`, `setup_requires`, `tests_require` | No optional or build-time dependencies declared. |

The most important gap is `packages`. To include a package, use `packages=find_packages()` or an explicit list such as `packages=["mypackage"]`. For a single module, use `py_modules=["mymodule"]`.

- Use `entry_points` with `console_scripts` for command-line tools.
